## 一、每个功能提测后，你拿到手第一步干什么？

### 1.1 接测五步法（每个功能都走一遍）

```
开发说"XX功能好了，可以测了"
         ↓
第①步  确认提测范围：这个功能改了哪些页面？涉及哪些端？有没有影响别的模块？
         ↓
第②步  环境验证：打开测试环境，这个功能入口能不能找到、页面能不能打开
         ↓
第③步  主流程跑通：先走一遍最基本的正向流程，能不能从头到尾走通
         ↓
第④步  按用例执行：打开对应模块的用例，逐条执行
         ↓
第⑤步  关联验证：这个功能会不会影响其他已测过的模块？简单回归
```

### 1.2 接测时必问开发的3个问题

| 问题 | 为什么要问 |
|------|-----------|
| **"这个功能涉及哪几个页面/接口？"** | 明确测试范围，不遗漏 |
| **"有没有改到其他模块的代码？"** | 判断是否需要回归其他模块 |
| **"第三方接口是真实的还是Mock的？"** | 决定能不能测到真实数据流转 |

### 🔴 第一批：管理后台（PC端，最先提测）

#### 模块A：分佣系统配置

**什么时候测**：后台分佣配置页面开发完成时

**测试思路**：
```
1. 先验证分佣比例能不能正常保存
   → 平台50% + 代理商50% → 保存成功？
   → 平台60% + 代理商50% = 110% → 保存失败？报什么错？

2. 再验证边界值
   → 0% / 100% / 负数 / 小数(8.5%) / 空值 → 各自什么反应？

3. 最后验证分销员比例
   → 一级10% + 二级5% 从代理商50%里扣 → 保存成功？
   → 一级30% + 二级25% = 55% > 代理商50% → 保存失败？
```

**对应用例**：fyxt-001~fyxt-026, fybc-001~fybc-012, fyxt-bl-001~002

**注意**：这时候还没有前端下单，分佣计算结果要等支付模块好了才能验

---

#### 模块B：选品仓库

**什么时候测**：选品仓库后台页面开发完成时

**测试思路**：
```
1. 一键同步能不能点？点了之后：
   → 按钮变loading了吗？（防重复点击）
   → 有没有进度提示？
   → 完成后"新增X个/更新Y个/失败Z个"对不对？

2. 同步下来的数据对不对？
   → 品牌名称/规格/价格/库存 和第三方一致吗？
   → 图片转存到OSS了吗？点开能看到吗？
   → 新品牌自动创建了吗？状态是"未上架"吗？

3. 变更检测能用吗？
   → 改一下第三方的价格，重新同步 → 标记"待确认"并自动下架了吗？
   → 运营确认后能重新上架吗？

4. 批量操作
   → 批量上架/批量删除能用吗？
   → 未选商品时按钮是灰的吗？

5. 异常情况
   → 第三方API挂了 → 提示"同步失败"吗？原来的数据还在吗？
   → 同步到一个品牌名为空的数据 → 跳过了吗？有提示吗？
```

**对应用例**：xpck-001~xpck-043

#### 模块C：订单管理 & 退款

**测试思路**：
```
1. 订单列表
   → 数据能加载吗？翻页正常吗？
   → 按type_id筛选能用吗？（外卖券/充值/餐饮各筛出来对不对）

2. 退款操作
   → 餐饮订单：有退款按钮吗？退款原因是必填的吗？
   → 虚拟商品（已完成）：退款按钮不能有！
   → 虚拟商品（FAIL）：有"重试发货"和"退款"两个按钮吗？

3. 退款金额校验
   → 退款>实付 → 拦截？
   → 退款=0 → 拦截？
   → 退款负数 → 拦截？
```

**对应用例**：ddzt-001~ddzt-026

### 🟡 第二批：用户端小程序（前端部署后）

#### 模块D：个人中心（登录/注册）

**优先测这个**——因为其他功能都依赖登录

**测试思路**：
```
1. 微信一键登录（最重要）
   → 打开小程序 → 弹出手机号授权弹窗了吗？
   → 点"允许" → 登录成功了吗？个人中心显示手机号了吗？
   → 点"拒绝" → 提示需要授权了吗？有重新授权入口吗？

2. 订单列表
   → 有订单的时候：列表加载正常？下拉刷新能用？触底加载更多？
   → 没订单的时候：空状态展示？

3. 佣金/余额（如果是代理商账号）
   → "预估收入"和"可提现余额"显示了吗？和后台数据一致吗？

4. 推广海报
   → 能生成吗？二维码清晰吗？能保存到相册吗？（需要相册权限）
```

**对应用例**：grzx-001~grzx-032, grzx-xcx-001~005

#### 模块F：外卖区

**测试思路**：
```
【红包（跳转类）】
1. 5个Icon都显示了吗？点击都能跳转吗？
2. 未安装App → 有提示或降级H5吗？

【通用券（交易类）】—— 重点！涉及资金

3. 微信支付 → 弹窗金额对吗？支付成功返回小程序了吗？
4. 支付成功后 → 卡密展示了吗？能复制吗？
5. 退款按钮 → 不能有！虚拟商品不退！
```

**对应用例**：wamhb-001~018, wamtyj-001~019, wamtyj-xcx-001~004

#### 模块G：餐饮折扣（最复杂，分三块测）

**G1 - 连锁品牌直跳**（简单）
```
品牌Logo显示 → 点击跳转第三方小程序/H5 → 链接带CPS参数
```

**G2 - 系统直连扫码**（涉及资金，重点）
```
1. 商家端输入金额 → 折扣自动算对了吗？（100元×8折=80元）
2. 生成二维码 → 用户扫码 → 支付确认页金额对吗？
3. 微信支付 → 成功后三端都看得到这笔订单吗？金额一致吗？
4. 二维码15分钟超时 → 扫了提示失效吗？
5. 退款 → 全额退/部分退都测一下 → 三端状态和金额都更新了吗？
6. 退款后分佣 → 佣金冲抵记录生成了吗？金额对吗？
```

**G3 - 人工辅助/验证码**（链路最长，最容易出Bug）
```
完整链路走一遍：
用户输入金额+上传凭证 → 提交 → 运营审核通过+输入验证码 → 用户收到通知
→ 用户到店出示验证码 → 商家核销 → 订单完成 → 分佣生成

每一步都可能出问题，重点关注：
- 凭证上传：JPG/PNG能传，PDF不能传，超10MB不能传
- 审核驳回：必须填理由，驳回后用户能重新提交吗？
- 验证码推送：订阅消息收到了吗？没授权的话短信收到了吗？
- 核销：输错5次锁15分钟吗？正确核销后订单变"已完成"吗？
```

**对应用例**：cyzkzt/cyzkxtzl/cyzkrg全系列 + xcx环境用例

## 三、每个模块测试时的"四步走"

不管测哪个模块，都按这个顺序：

```
第1步：正向主流程（P0用例）
    → 最基本的功能能不能用？从头到尾走一遍
    → 如果主流程都走不通，直接打回，不继续测

第2步：反向/异常（P1用例）
    → 输入不合法的数据会怎样？
    → 该有权限的有吗？不该有的没有吗？
    → 断网/弱网/超时怎么处理？

第3步：边界值和特殊场景（P2用例）
    → 金额为0/0.01/50000/50000.01
    → 极端数据、并发操作

第4步：小程序环境验证（xcx用例）
    → 微信支付弹窗、扫码、授权、分享、键盘交互等
```

## 四、Bug要怎么记录？

### 4.1 Bug模板

```
【Bug标题】[模块名] 简述问题
【环境】iOS 16 / 微信8.0.x / 测试环境
【复现步骤】
  1. xxx
  2. xxx
  3. xxx
【预期结果】xxx
【实际结果】xxx
【截图/录屏】（附图）
【严重程度】P0/P1/P2/P3
```

### 4.2 严重程度判断标准

| 级别 | 什么情况 | 举例 |
|------|---------|------|
| **P0-阻塞** | 核心功能不可用，阻塞其他测试 | 登录失败、支付报错、数据库崩溃 |
| **P1-严重** | 功能不可用但有替代方案，或资金相关 | 分佣算错、退款金额不对、权限穿透 |
| **P2-一般** | 功能可用但体验差 | 文案错误、布局错位、loading缺失 |
| **P3-建议** | 不影响功能，体验优化 | 颜色不统一、交互不够流畅 |


## 八、特别注意事项

### 8.1 涉及资金的模块要格外仔细

```
通用券支付、餐饮扫码支付、充值支付、电影购票、提现打款
→ 这些功能每一分钱都要算对
→ 用分佣对照表逐条核对
→ 退款后佣金冲抵金额要重算一遍
```

### 8.2 三端一致性——每次涉及订单/金额的操作后

```
用户端看一眼 → 商家端看一眼 → 后台看一眼
三个地方的订单状态、金额、时间必须一致
```

### 8.3 安全测试不要忘

```
- 用Postman改一下请求里的订单ID → 能看到别人订单吗？（不能！）
- 虚拟商品订单直接调退款API → 能退吗？（不能！）
- 搜索框输入 ' OR 1=1 -- → 返回正常吗？（不能报SQL错误！）
```

### 8.4 还有13个待确认的需求问题

```
测试过程中如果遇到不确定的行为（比如验证码到底几位？结算周期多久？），
先按"最合理的预期"记录，同时在Bug/问题中标注"待确认"，
不要因为需求没说清就跳过不测。
```
