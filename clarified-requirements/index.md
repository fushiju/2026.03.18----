# "快乐羊毛"平台需求整理

## 1. 项目概述
综合性优惠生活服务平台，整合第三方电商、本地生活服务及虚拟充值资源，为用户提供省钱优惠。构建分佣体系，支持代理商和分销员推广。

## 2. 用户端功能（小程序）

### 2.1 免费资料区
- 展示电子档资源（行业报告、学习资料、教程等）
- 列表展示：标题、简介、更新时间
- 详情页：显示资料链接（可配置多个）
- 交互：点击"复制链接"按钮，提示复制成功
- 后台：支持资料增删改查、分类管理

### 2.2 外卖区
#### 2.2.1 红包（CPS跳转）
- 支持平台：美团、饿了么、淘宝、京东、美团拼好饭
- 点击Icon -> 中间页加载参数 -> 跳转App领券页面
- 对接渠道：美赚、聚推客、凡点（优选/轮询逻辑）

#### 2.2.2 通用券（平台交易）
- 商品：美团通用券
- 流程：选择面额 -> 购买支付 -> 下发卡密/券码
- 对接：蜂助手、骑士

### 2.3 餐饮折扣
#### 2.3.1 连锁品牌直跳（CPS模式）
- 适用：麦当劳、肯德基、星巴克等
- 展示品牌Logo、优惠活动Banner
- 点击跳转品牌官方小程序/H5
- 对接：骑士、凡点

#### 2.3.2 品牌会员共享（模式一：系统直连）
- 适用：有收银系统、配合接入的品牌
- 核心流程：
  1. 商家输入消费原价（如100元）
  2. 系统按折扣率自动计算实付（如8折=80元）
  3. 生成支付二维码
  4. 用户确认并完成微信支付，资金进入平台账户
  5. 订单状态变更为"已支付"
- 售后：支持退款，原路退回
- 角色权限：品牌商户和门店子账号

#### 2.3.3 品牌会员共享（模式二：人工辅助/验证码模式）
- 适用：无系统对接，代理商拓展
- 基础设置：
  - 商户录入：商家名称、地址、电话、品牌、折扣设置、会员充值账号
  - 新商家需审核通过后展示
- 用户下单流程：
  1. 选择商家 -> 点击"去买单"
  2. 输入消费总金额（原价）
  3. 上传商家小票/账单照片或支付截图
  4. 系统计算折扣（如原价100，折后85）
  5. 提交订单，状态为"待审核"
- 运营审核：
  1. 查看用户上传照片和金额
  2. 驳回：凭证不清或金额不符
  3. 通过：获取验证码 -> 输入验证码 -> 确认下发
- 验证码核销：
  - 系统通过订阅消息或短信发送验证码
  - 用户展示验证码给商家收银员
  - 商家确认后允许折扣离开
- 订单完成：状态变更为"已完成"，自动计算分佣

### 2.4 打车服务
- 聚合打车入口
- 获取当前位置，跳转第三方平台（滴滴、高德等）
- 对接：凡点、美赚、聚推客

### 2.5 电影票务
- 在线选座购票
- 流程：选影片 -> 选座 -> 确认订单 -> 支付 -> 出票
- 对接：芒果或其他供应商（需选座接口）

### 2.6 会员充值
- 视频会员（腾讯、爱奇艺）、话费、电费充值
- 流程：商品列表 -> 选面额/账号 -> 支付 -> 直充到账
- 对接：骑士、蜂助手

### 2.7 家电购物（京东联盟）
- 京东家电专属优惠链接
- 展示精选家电（图片、价格、预估返利）
- 点击"购买"跳转京东App下单
- 对接：辛贝（京东联盟）
- 后台手动配置商品佣金比例

### 2.8 购物返利
- 涵盖京东、淘宝、抖音、唯品会、拼多多
- 授权绑定：首次使用授权平台账号
- 转链逻辑：复制链接 -> 粘贴 -> 生成推广链接 -> 跳转购买
- 订单跟踪：定期同步（已下单、已结算、已失效）

### 2.9 寄快递（待定）
- 快递比价与下单
- 对接：凡点或聚推客

### 2.10 个人中心
- 登录/注册：微信一键登录（需获取手机号）
- 我的订单：查看所有平台下单记录
- 佣金/余额：预估收入及可提现余额
- 推广中心：生成推广海报、二维码，查看下级分销员数据

## 3. 商家端功能

### 3.1 账号体系
- 品牌商户提交资质入驻，审核通过创建主账号
- 主账号可创建、启用、禁用门店子账号

### 3.2 门店运营
- 收银台：输入消费金额，显示折扣金额，生成收款二维码
- 订单管理：查看核销订单列表
- 退款：发起退款申请，查看退款状态

### 3.3 数据统计
- 今日/本月流水、核销笔数

## 4. 后台管理系统

### 4.1 基础管理
- 用户管理、角色权限管理、系统配置

### 4.2 商品与CMS管理
- 资料管理、商品管理、品牌折扣管理（创建品牌、绑定门店、设置折扣规则）

### 4.3 订单与财务管理
- 订单列表、对账管理、退款审核

### 4.4 分佣系统
- 分佣配置（代理商、分销员比例等级）
- 餐饮折扣分佣、直充/券类分佣
- 佣金手动录入（Excel导入）
- 结算管理（提现申请处理）

### 4.5 消息通知
- 模板消息：下单成功、退款成功、佣金到账、核销提醒

## 5. 订单状态流转与退款规则

### 5.1 核心业务规则
- 原则：支付即交付，支付即完成
- 适用：外卖券、会员充值、电影票、购物返利/家电/打车/外卖红包
- 例外：餐饮折扣（扫码支付）保留退款功能

### 5.2 订单状态机
| 状态编码 | 状态名称 | 描述 |
|---------|---------|------|
| WAIT_PAY | 待支付 | 订单创建，等待付款 |
| PENDING_AUDIT | 待审核 | 用户已付款并上传凭证（餐饮模式二） |
| DELIVERING | 发货中 | 系统处理发货（请求第三方接口） |
| COMPLETED | 已完成 | 发货成功，订单锁定禁止退款 |
| FAIL | 失败 | 充值/发券失败 |
| REFUNDED | 已退款 | 退款成功 |

### 5.3 前端交互要求
- 下单确认页：红色醒目提示"虚拟商品支付后不支持退款"
- 勾选框："我已阅读并同意：本商品支付后不退款"
- 订单详情页：虚拟商品隐藏"申请退款"按钮
- 支付成功页：直接展示结果（卡密、充值成功提示）
